# RegardingAds

The design and publishing framework behind [RegardingAds](https://regardingads.com/), packaged with **five sample advertisements** so you can make it your own. Use it for another advertising archive, a design collection, a catalog, or a different editorial project.

This is a small, standalone starter, not the full RegardingAds archive. It keeps the original visual design, responsive collection grid, detail pages, and Markdown publishing model. The idea of making the site available for others to reuse was inspired by [Uses This](https://usesthis.com/about/) and [its public repository](https://github.com/waferbaby/usesthis). No Uses This code is included.

## Start locally

Use **Node.js 24 LTS** (`.nvmrc` is included) and npm. No API keys, CMS account, database, or OCR service is required to run this starter.

```sh
npm ci
npm run dev
```

Open the local address printed by Astro, normally `http://127.0.0.1:4321`.

```sh
npm run build   # Type-check and generate dist/
npm test        # Check the generated site; run after building
npm run preview # Preview dist/ locally
```

## What is included

- Astro static output with five Markdown entries and their five source images.
- Responsive WebP images generated by Astro.
- Filters for decade, industry, and tag, with shareable URLs and pagination at 12 entries per page.
- A complete server-rendered collection that stays accessible without JavaScript.
- Detail pages with commentary, expandable original copy, and previous/next navigation.
- Canonical URLs, Open Graph metadata, JSON-LD, sitemap, and robots.txt.
- Optional [Pages CMS](https://pagescms.org/) configuration in `.pages.yml`.
- Automated build and regression checks in GitHub Actions.

The examples are the first five entries by the original archive's `order`: Triumph Spitfire (1978), Volkswagen Scirocco (1984), Volkswagen Rabbit (1980), Volkswagen Pickup (1980), and Volkswagen Dasher (1983). See [the content notice](CONTENT-NOTICE.md) for provenance and rights.

## Make it yours

1. Set `site` in `astro.config.mjs` to your public origin. It defaults to `https://example.com` so forks do not generate canonical links to RegardingAds. Tests read this same configuration.
2. Edit `src/layouts/Layout.astro` for the wordmark, navigation, footer, and default metadata. Replace `public/favicon.svg`.
3. Edit the introduction and About section in `src/pages/index.astro`.
4. Update titles, descriptions, and structured data in `src/lib/seo.ts`, including the site name and advertising-specific terminology.
5. Adjust typography, colors, and spacing in `src/styles/global.css`.
6. Replace the sample entries and images. Adapt the schema, templates, filters, CMS fields, and relevant test expectations together if your collection is about something other than advertisements.

Keep the `collection-grid`, `collection-card`, and `entry-*` CSS hooks consistent when editing templates and styles; filters and tests use some of them. The collection class names also avoid common content-blocker rules for advertisement-like elements.

The starter is configured for deployment at a domain root. Subdirectory hosting, including a GitHub Pages project path, needs additional work to make the root-relative links and asset paths honor a base path. A GitHub repository does not require GitHub Pages hosting.

Production analytics, search-verification identifiers, legacy redirects, import records, original build output, local maintenance instructions, and OCR caches are intentionally omitted. Analytics are not enabled.

## Add an entry

Put a publication image in `src/assets/ads/` and create `src/content/ads/my-example-1984.md`. The filename becomes `/ads/my-example-1984/`.

```yaml
---
brand: "Example"
title: "A headline worth remembering"
year: 1984
industry: "Consumer Goods"
image: "../../assets/ads/my-example-1984.jpg"
imageAlt: "Describe the actual image and its important composition."
orientation: "Portrait"
tags: ["Craftsmanship", "Value", "Wit"]
themes: []
ocr: |-
  Transcribe the original words here, if relevant.
published: true
order: 6
---

Write your commentary here in Markdown.
```

Use real metadata and appropriate tags for the item. Existing examples use three tags each. `sourceUrl` is optional and should point to real provenance. Optional quoted `date` and `dateModified` values use `YYYY-MM-DD`: the former records actual archive publication, not the historical ad year; the latter requires `date` and cannot precede it. Leave unknown dates absent. Use `Landscape` for a landscape image. `themes` is retained as metadata but is not displayed.

Only entries with `published: true` receive routes or collection cards. Draft entries are still parsed and their images may be processed during builds; keep confidential material outside the project. Run `npm run build` and `npm test` after changes.

## Deploy

Set your own site URL, run `npm ci`, then `npm run build` and `npm test`. Publish the contents of `dist/` to a static host. For hosts that build from Git, use `npm run build` as the build command and `dist` as the output directory. GitHub Actions validates the project and does not deploy it.

Do not commit `node_modules/`, `.astro/`, `dist/`, environment files, credentials, private scans, or OCR caches. The included `.gitignore` excludes these common local artifacts.

## Publish the repository on GitHub

This directory is the repository root; there is no surrounding `astro-site` folder to upload. Review [LICENSE](LICENSE) and [CONTENT-NOTICE.md](CONTENT-NOTICE.md), and inspect `git status` before publishing.

Create an empty **public** GitHub repository named `regarding-ads-starter`, without an auto-generated README or license. From this directory:

```sh
git init -b main
git add .
git commit -m "Initial release of RegardingAds Astro starter"
git remote add origin https://github.com/YOUR-USERNAME/regarding-ads-starter.git
git push -u origin main
```

If Git is already initialized, skip `git init`. You can enable **Template repository** in the repository settings so others can use GitHub's “Use this template” action. Suggested description: “An Astro collection starter based on RegardingAds, with five sample advertisements.” Suggested topics: `astro`, `static-site`, `starter-template`, `design`, `archive`.
